# ADR-0001：非破坏编辑图是唯一编辑真相

- 状态：Proposed
- 日期：2026-07-25
- 关联：CORE-002、CORE-003、PRO-001、SEC-002

## 背景

快捷操作、专业图层、预设、AI 生成和自然语言若各自保存结果，会产生：

- 一键结果无法细调；
- 预览与导出逻辑不同；
- 撤销和项目恢复不完整；
- 模型更新改变旧工程；
- 批处理和插件重复实现。

## 决定

使用版本化非破坏编辑 DAG 作为文档唯一真相：

- 原始源不可变；
- 所有编辑表示为有类型、有版本、有参数的节点和蒙版；
- 用户图层树是 DAG 的稳定视图；
- 渲染图是设备相关的临时编译产物；
- 分析结果是可缓存派生资产，不直接改像素；
- 生成式结果保存冻结补丁、Alpha 和来源；
- 所有正式修改组成原子事务和不可变快照；
- 快捷与专业模式使用同一文档。

## 结果

正面：

- 一键结果可展开、调弱和撤销；
- 项目可复现、比较和分支；
- 模型可替换；
- 缓存与 GPU 优化不影响语义；
- 自动、手动、批量和插件可组合。

代价：

- 项目 Schema、迁移、缓存失效和节点版本复杂；
- 生成资产增加磁盘占用；
- 部分第三方效果缺失时需冻结或占位；
- 工程初期速度慢于直接把效果烘焙到位图。

## 被否决方案

### 每次操作直接改像素

实现快，但无法满足专业可编辑、自然语言复合操作和稳定项目恢复。

### 仅用线性历史

能撤销但不适合图层组合、复用蒙版、分支和局部重算。

### AI 结果全部栅格化

旧结果稳定，但自动结果黑盒，无法达到用户要求的自动/手动协同。

## 验证

- 同一快捷操作展开到专业模式，像素完全一致；
- 删除所有缓存后重渲染一致；
- 1000 次命令/撤销/重做后哈希正确；
- 模型包缺失时冻结生成结果仍可打开；
- 强制终止后只丢失未提交预览。
