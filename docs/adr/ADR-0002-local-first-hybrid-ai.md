# ADR-0002：本地优先、显式授权的混合 AI

- 状态：Proposed
- 日期：2026-07-25
- 关联：SEC-001、SEC-005、NL-004、POR-005

## 背景

人像、婚礼和家庭照片高度敏感。完全云端可减少本地模型负担，却带来上传、保留、地区、成本和离线问题；完全本地则难以覆盖大面积高质量生成式任务和低端硬件。

## 决定

- 检测、分割、matting、深度、基础人像、传统修复和 QA 默认本地；
- 基础编辑在完全离线、未登录状态可用；
- 云端只通过 Provider，初始策略为每任务询问；
- 只上传任务所需 ROI 与上下文；
- 授权绑定提供方、区域、照片范围和用途；
- `local_only` 是强约束，不允许自动降到云；
- 用户素材默认不用于训练；
- 企业可锁定 Provider 和模型版本；
- 云结果作为冻结资产进入项目，断网不影响重开；
- UI 持续显示本地/云端状态。

## 结果

正面：

- 私人照片默认不离机；
- 离线可靠；
- 能按需使用更强生成能力；
- Provider 可替换；
- 成本和数据边界可解释。

代价：

- 需要分发较大的本地模型；
- 多种硬件适配和降级复杂；
- 本地与云结果需要分别评测；
- 同一操作的耗时可能因设备差异较大。

## 被否决方案

### 完全云端

不满足本地优先、离线和企业数据边界。

### 完全本地

会限制低端设备和大面积生成式能力；仍保留为用户可选策略。

### 一次全局同意所有云端处理

范围过宽，无法说明单次是否包含人脸、整图或不同提供方。

## 验证

- 离线模式抓包无应用网络流量；
- ROI 任务不会上传整图；
- Provider 改变时重新授权；
- 云端取消/断线不产生半事务；
- 云模型下线后旧项目冻结结果可打开；
- 日志和遥测不含像素、提示原文或人脸特征。
