# 功能详细规格

## 1. 通用规格模板

每个智能功能都必须输出：

- 目标实例与作用范围；
- 可编辑蒙版；
- 至少一个非破坏编辑节点；
- 推荐强度和参数范围；
- 使用的模型/算法与本地/云端标识；
- 低置信度区域；
- 预览候选；
- 任务专用 QA 结果；
- 取消、重试、换候选、手动接管和回滚入口。

## 2. 专业编辑底座

“达到专业水准”首先依赖完整底座，而不是 AI 数量。

### 2.1 文件与 RAW

- 非破坏 RAW 显影：黑白电平、去马赛克、白平衡、高光恢复、RAW 降噪、相机配置；
- 镜头配置：畸变、暗角、色差、锐度衰减；
- JPEG、PNG、TIFF、HEIF、OpenEXR 逐步支持；
- PSD/PSB 按明确兼容矩阵导入/导出，不支持的效果可选栅格化副本；
- EXIF/IPTC/XMP 保留、编辑和导出时位置清理；
- 8/16/32 位、SDR/HDR、ICC 与软打样。

### 2.2 编辑工具

- 图层、组、调整层、蒙版、剪贴蒙版、智能对象和混合模式；
- 矩形、椭圆、套索、磁性/对象/主体选区、颜色范围和通道选区；
- 画笔、渐变、修复、仿制、内容填充、加深减淡；
- 曲线、色阶、白平衡、曝光、HSL、色彩平衡、可选颜色、LUT、颗粒；
- 裁剪、拉直、透视、自由变换、网格变形和受控液化；
- 文字、简单形状、水印和版式画布；
- 对齐、吸附、标尺、参考线、测量和像素检查。

所有工具支持参数输入、快捷键、压感和非破坏式应用。

## 3. 人物照片精修

### 3.1 一键人像

分析：

- 人物实例、脸部姿态、遮挡和可见度；
- 皮肤、五官、头发、牙齿、衣物和背景；
- 曝光、白平衡、肤色、油光、黑眼圈和临时瑕疵；
- 相机噪点、景深和局部光向。

推荐配方：

- 自然人像；
- 婚礼柔光；
- 棚拍清晰；
- 逆光修复；
- 夜景人像；
- 商业精修。

每个配方拆为独立节点，不以一个不可解释的“美颜度”烘焙。

### 3.2 瑕疵

系统将候选分为：

- 临时瑕疵：痘痘、灰尘、脱妆、小划痕，可自动勾选；
- 可能永久特征：痣、雀斑、疤痕、皱纹，默认不勾选；
- 不确定：以标记供用户确认。

用户可批量确认，也可用修复/保护画笔修订。自动补丁从相近肤区多源采样，检测重复毛孔。

### 3.3 磨皮

管线分离：

1. 大尺度明暗；
2. 中尺度色斑与起伏；
3. 小尺度毛孔和汗毛；
4. 眼、眉、鼻翼、唇线、发际线保护。

默认优先修正大/中尺度，保留小尺度。参数包括平滑、肤色均匀、油光、黑眼圈、纹理保护、细纹保留、局部 Dodge & Burn。

QA：

- 皮肤频谱损失；
- 五官边缘清晰度；
- 色块与晕圈；
- 颈部/手臂/脸部色彩关系；
- 重复纹理。

### 3.4 五官、视线和表情

自动模式根据脸宽、瞳距等相对尺寸限制形变。手动模式提供关键点、网格、冻结蒙版、局部液化和数值输入。

必须保护：

- 虹膜圆度、瞳孔与高光；
- 眼睑遮挡和双眼合理会聚；
- 唇线、牙齿、法令纹和脸颊联动；
- 发际线、耳朵、眼镜、首饰；
- 背景直线和重复图案。

禁止默认镜像一只眼替换另一只眼，禁止把自然不对称机械对称化。位移超过自然阈值时只生成候选。

### 3.5 身形、姿态与衣物

- 按头颈、肩、躯干、四肢和关节建立保护网格；
- 小幅、多次形变优先于一次大推拉；
- 固定脚底和重心，保持相对透视；
- 保护手指、衣物图案、首饰和背景；
- 调整轮廓后同步检查褶皱、高光和阴影；
- 提供“弱 / 建议 / 强”，默认“弱”或“建议”。

## 4. 风景照片精修

### 4.1 一键风景

语义区域：天空、云、山、植被、水面、雪、建筑、道路和远景雾。

处理顺序：

1. RAW 和镜头校正；
2. 地平线与透视；
3. 全局动态范围；
4. 按深度恢复局部对比；
5. 天空/地面独立曝光和白平衡；
6. 植被、水面、雪地的颜色保护；
7. 噪点、锐化和输出。

避免：

- 地平线和山脊光晕；
- 过度去雾造成黑边；
- 过饱和绿色和蓝色；
- 云层纹理断裂；
- 阴影硬拉导致色噪。

### 4.2 建筑和城市

- 自动水平和垂直线候选；
- 可视消失点与透视网格；
- 建筑修正后自动裁剪或生成边缘，二者明确区分；
- 夜景高光和霓虹色域保护；
- 文字、招牌和窗格结构加入对象移除保护。

### 4.3 高级合成

P1 支持 HDR、全景和焦点堆栈。自动对齐失败时允许设置锚点、排除帧和手动选择融合区域；运动物体去鬼影结果可视化。

## 5. 宠物照片精修

宠物使用独立分析模型，不复用人类皮肤逻辑。

目标区域：

- 左右眼、鼻、嘴、耳、舌；
- 长毛、短毛、胡须和半透明毛边；
- 身体、爪、尾；
- 项圈、衣物、牵引绳；
- 多宠物实例。

功能：

- 白毛高光与黑毛阴影恢复；
- 眼睛清晰、适度提亮和反光修复；
- 泪痕减淡但保留毛向；
- 鼻部局部明暗；
- 毛色白平衡与自然锐化；
- 毛发 Alpha 蒙版、背景虚化/替换；
- 牵引绳和背景杂物移除。

保护：

- 品种特征、虹膜形状、鼻纹和独特毛色；
- 胡须不能被误删；
- 锐化不能形成白边；
- 移除牵引绳不能生成异常肢体或重复毛纹。

## 6. 替换天空

### 6.1 工作流

1. 天空语义分割；
2. 树叶、发丝、电线、塔尖和透明物精细 Alpha；
3. 地平线、焦距感、太阳方向和景深估计；
4. 从本地库、自有图片或获准云端生成选择候选；
5. 天空位置、缩放、旋转和大气透视匹配；
6. 前景色温、曝光、方向光和环境光候选；
7. 水面、玻璃、湿地反射候选；
8. 边缘去污染、噪点和颗粒匹配；
9. 光色/边缘 QA。

### 6.2 手动参数

- 位置、缩放、旋转、地平线；
- 边缘收缩/扩张、羽化、去色边；
- 天空曝光、色温、饱和度、对比；
- 前景重光照、雾化、阴影强度；
- 景深、噪点、颗粒；
- 反射位置、模糊和强度。

天空资产记录来源、许可、拍摄方向、太阳位置、动态范围和地平线。无法可靠识别天空时进入辅助选区，不静默执行。

## 7. 预设与滤镜

预设是版本化“编辑图片段”，可包含：

- 曲线、HSL、色彩分级、颗粒、晕影；
- 3D LUT；
- 动态范围和白平衡自适应规则；
- 人物、肤色、天空、背景等语义蒙版；
- RAW/HDR/工作空间兼容说明；
- 作者、版本、依赖、缩略图和许可。

预览：

- 先在代理图上批量生成缩略图；
- 选中后直接把节点片段接入编辑图；
- 导出使用原图和最终质量，不用缩略结果；
- 缓存按图像指纹、预设版本和渲染配置失效。

批量应用时固定风格参数，但逐张重新估计曝光、白平衡和语义蒙版。用户可锁定参数避免漂移。

## 8. 移除路人或物品

### 8.1 目标定义

入口：点击、画笔、套索、矩形、对象列表、自然语言。“移除所有背景人物”先列出实例，主角不会被默认包含。

蒙版自动扩展到：

- 接触阴影与投影；
- 水面/玻璃反射；
- 边缘颜色污染；
- 与目标一体的随身物品。

### 8.2 分区修复

待修区域按以下类别拆分：

| 类别 | 优先方法 |
|---|---|
| 小瑕疵 | 邻域修复 |
| 草地、墙面等纹理 | 多源 PatchMatch / 纹理合成 |
| 道路线、栏杆、墙缝 | 结构线和透视引导修复 |
| 阴影/反射 | 独立连续场重建 |
| 大型复杂遮挡 | 有上下文的生成式补全 |
| 文字、标志 | 默认保护或要求用户确认重建 |

顺序必须为：结构 → 阴影/反射 → 纹理 → 噪点/锐度。

### 8.3 候选与 QA

- 默认三个候选；
- 可锁定正确区域，只重试局部；
- 可选择或画出采样源；
- 显示替换范围和推断区域；
- 检测直线断裂、重复纹理、接缝、模糊斑、文字变形和异常语义；
- 背景信息不足时明确说明“生成的是合理补全，不是真实还原”。

## 9. 主体抠图、背景与合成

- 主体检测后按硬边、皮肤软边、头发/毛发、薄纱/玻璃分类；
- Alpha 蒙版支持用户增减层，模型更新不覆盖手工修改；
- 去除原背景颜色污染；
- 合成时先对齐地平线、比例和接触点，再匹配色彩；
- 接触阴影、投影和环境遮蔽分层；
- 曝光、白平衡、光向、景深、锐度、噪点和压缩特征分别匹配；
- QA 检查漂浮、贴纸边、光晕、阴影方向和背景弯曲。

## 10. 额外建议能力

### P0/P1

- 智能主体/对象选择与边缘精修；
- 背景虚化和镜头景深模拟；
- AI 降噪、去模糊、超分辨率；
- 自动构图、水平和透视；
- 人物/背景分区重打光；
- 老照片灰尘、划痕和褪色修复；
- 批量筛选、相似图和闭眼/失焦提示；
- 跨照片肤色和风格一致性；
- 导出配方、水印和元数据清理。

### P2/P3

- 可选联机审片与团队资产库；
- 可沙箱化插件和工作流市场；
- 内容凭证与编辑来源验证；
- 拍摄现场联机导入；
- 多显示器和专业控制台映射。

## 11. 功能验收通则

- 一键结果能进入专业模式继续编辑；
- 手工修订不被模型刷新覆盖；
- 代理预览和最终导出不存在可见逻辑差异；
- 低置信度不静默执行；
- 本地/云端处理路径清晰；
- 锁定目标和保护区域在复合操作中生效；
- 长任务可取消且不会留下半提交节点；
- 导出失败不会损坏项目；
- 所有外貌修改和生成内容均有可追踪来源。
