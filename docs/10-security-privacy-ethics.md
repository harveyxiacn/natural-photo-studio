# 安全、隐私与伦理

## 1. 保护对象

照片编辑项目可能包含：

- 原始像素、RAW、PSD/TIFF 和生成补丁；
- 人脸、身体、儿童、宠物和家庭关系；
- EXIF/GPS、拍摄时间和设备信息；
- 文件路径、客户名、项目名和导出历史；
- 自然语言提示与审阅意见；
- 人脸关键点、分割、深度等派生资产；
- 云端凭据、模型包、插件和更新包。

其中照片、位置和人脸派生信息默认视为 `Private`；凭据和密钥为 `Secret`。

## 2. 数据分类

| 等级 | 示例 | 默认策略 |
|---|---|---|
| Public | 产品文档、无隐私的演示素材 | 可公开 |
| Internal | 脱敏性能日志、构建信息 | 限定团队 |
| Private | 用户照片、项目、提示、局部预览 | 本地授权范围，最短保留 |
| Restricted | 儿童/客户敏感照片、人脸派生资产 | 本地优先、加密、严格审计 |
| Secret | Token、证书、插件签名私钥 | 系统安全存储，永不记录 |

## 3. 隐私默认值

- 原图和派生分析默认只在本机；
- 云端 AI 初始策略为“每次询问”；
- 能局部处理时只上传目标 ROI 与必要上下文；
- 用户素材默认不用于训练；
- 遥测默认不含像素、完整路径、文件名、提示原文或人脸特征；
- 社交分享默认移除 GPS；
- 临时代理有配额、寿命和一键清理；
- 完全离线模式不依赖登录也能进行基础编辑和导出；
- 企业模式可禁用云端、插件网络和模型自动更新。

## 4. 威胁模型

| 威胁 | 典型路径 | 主要控制 |
|---|---|---|
| 恶意图片/RAW | 编解码漏洞、超大尺寸声明 | 低权限 Codec Worker、资源上限、模糊测试 |
| 恶意项目包 | 路径穿越、ZIP 炸弹、递归引用 | 安全解包、校验和、深度/比例/总量上限 |
| 恶意插件 | 读取相册、联网外传、原生代码 | 默认拒绝权限、WASM/进程隔离、签名与吊销 |
| 恶意模型 | 供应链替换、运行时利用 | 清单、哈希、签名、许可、隔离 AI Worker |
| 自然语言越权 | 提示注入、图片 OCR 指令 | 受限 DSL、能力校验、数据与指令隔离 |
| 云端泄露 | 过量上传、保留策略不符 | ROI 最小化、明确授权、提供方审计、删除证明 |
| 日志/缓存泄露 | 崩溃包带照片或路径 | 脱敏、预览诊断包、短寿命、访问权限 |
| 文件覆盖 | 导出同名、路径混淆 | 原图只读、临时写入、原子提交、版本化命名 |
| 更新劫持 | DNS/镜像/回滚到漏洞版 | 代码签名、元数据签名、防回滚、分阶段发布 |
| 项目损坏 | 崩溃、磁盘满、迁移失败 | WAL、对象哈希、迁移备份、只读恢复 |

## 5. 云端处理授权

首次使用或策略变化时必须显示：

- 提供方与处理地区；
- 使用哪项功能；
- 上传整图、ROI 还是代理图；
- 预计像素范围和分辨率；
- 是否包含人脸；
- 用途、费用或额度；
- 服务端保留时限和删除方式；
- 本地替代及质量差异。

授权粒度：

```text
deny        完全禁止
ask         每个任务确认（默认）
allow_project  当前项目在明确范围内允许
local_only  强制本地；不允许自动降到云
enterprise_policy  由组织策略锁定
```

一个授权不能从当前 ROI 扩大到整张、从当前照片扩大到整组，或从某提供方扩大到另一提供方。

## 6. 人脸与外貌编辑

### 6.1 原则

- 不把脸型、肤色、年龄、体型和不对称描述为客观“缺陷”；
- 默认修复技术问题和临时瑕疵，不主动重塑身份；
- 痣、雀斑、疤痕、皱纹和品种特征默认保留；
- 显著五官、身形、年龄或身份变化必须预览并确认；
- 每个人物可独立锁定；
- 身份相似度等特征仅在本次编辑本地用于变化告警，不用于建库、识别或营销；
- 未成年人照片不做年龄推断、广告画像或默认成人化修饰。

### 6.2 高风险操作

- 换脸或复制他人身份；
- 伪造证件、医疗或新闻证据；
- 明显改变年龄、种族特征或身份；
- 未经明确选择的性化修改；
- 大面积重建被遮挡面部或身体。

产品不提供用于冒充的通用换脸工作流。对于合理的闭眼修复或家庭照片修复，应使用同一人物经授权参考、明确标记生成范围并保留原版本。

## 7. 生成式内容与真实性

- 生成式补丁记录模型、版本、区域、时间和候选；
- 对象移除说明“合理补全”不等同于真实还原；
- 可选在导出元数据或伴随清单中记录生成范围；
- 新闻、取证、档案模式默认禁用或显著标记生成式编辑；
- 不生成或移除水印来混淆所有权；
- 天空、背景和素材库必须保存许可；
- 产品支持内容凭证的接口，但不对所有外部平台的显示作保证。

## 8. 文件与项目安全

- 所有外部路径规范化并使用选择器/授权句柄；
- 拒绝 `..` 逃逸、设备路径、危险符号链接和非常规流；
- 不在主进程解压不可信项目；
- 限制像素总数、图层/节点数、蒙版大小、项目递归和压缩比；
- 项目写入使用临时文件、哈希、原子重命名和数据库事务；
- 原图默认只读，导出不覆盖源；
- 缓存目录不使用客户名；
- 项目加密需使用成熟库和系统密钥，不自创密码算法。

## 9. 插件与模型供应链

- 插件、模型、应用和更新包均验证签名与哈希；
- 模型 manifest 必填来源、许可证、商用状态、运行时和文件哈希；
- 第三方插件默认 WASM/隔离进程；
- 权限安装时可见，网络限制到声明域名；
- 插件不直接访问数据库、密钥或任意 GPU 地址；
- 支持签名吊销、恶意版本远程禁用和安全模式；
- 发布构建生成 SBOM，扫描依赖漏洞和许可证；
- 高危依赖漏洞未处置不得发版。

## 10. 凭据和网络

- 凭据存入 Windows Credential Manager / macOS Keychain 等系统存储；
- TLS 证书验证不可关闭；
- Provider 请求带最小授权令牌、超时、重试和取消；
- 日志不输出请求正文、Authorization、Cookie 或签名 URL；
- 插件网络和应用 Provider 使用不同身份；
- 网络代理与企业证书由明确设置管理；
- 离线模式从网络层阻断，而不只隐藏按钮。

## 11. 日志、遥测和诊断

允许：

- 版本、平台、设备类别；
- 操作类型和稳定错误码；
- 图片尺寸桶、位深和颜色空间类别；
- 耗时、内存/显存、缓存命中；
- 模型版本、降级路径和 QA 分数；
- 崩溃堆栈中的应用符号。

默认禁止：

- 像素、缩略图和蒙版；
- 完整路径、文件名和项目名；
- 提示原文、OCR、人物标签；
- 人脸关键点、嵌入或身份 ID；
- Token、Cookie 和系统用户名。

诊断包必须先展示文件列表和脱敏摘要，用户可删除条目后再导出。诊断模式有醒目标识和自动过期。

## 12. 缓存、删除和保留

- 缓存大小和生命周期可配置；
- 隐私模式关闭项目时清除代理、模型输入和云端下载；
- “清除项目缓存”不删除正式对象；
- 删除项目先进入应用回收站，保留期可配置；
- 安全删除受 SSD/文件系统限制，界面不能虚假承诺不可恢复；
- 云端删除显示请求状态和提供方承诺，不声称已物理擦除；
- 退出账号时撤销令牌并允许清除本地云缓存。

## 13. 事件响应

严重度：

- `SEV-0`：原图损坏、密钥/私人照片外泄、更新供应链；
- `SEV-1`：项目不可恢复、高危沙箱逃逸、未授权上传；
- `SEV-2`：局部数据或权限异常，有安全替代；
- `SEV-3`：低影响缺陷。

流程：

1. 停止受影响发布、模型或插件；
2. 保全脱敏证据；
3. 撤销令牌和签名，阻断版本；
4. 评估受影响范围；
5. 发布修复、回滚或删除指引；
6. 按适用法律/合同通知；
7. 完成根因分析和防复发门禁。

## 14. 安全发布门槛

- 未解决严重/高危漏洞为零；
- 高风险自然语言命令漏确认率为零；
- 未授权像素网络传输为零；
- 项目/图片/模型/插件解析通过模糊和资源耗尽测试；
- 更新、模型和插件签名验证不可被配置绕过；
- 故障注入下原图不覆盖、已提交事务不丢失；
- 日志、遥测和诊断包通过自动敏感信息扫描；
- 云端 Provider 的数据处理协议和删除策略完成审查。

本文是产品与工程设计，不替代针对目标市场的正式法律、合规和无障碍审查。
