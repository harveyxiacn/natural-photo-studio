# 质量、性能与测试

## 1. 质量模型

产品质量由六类指标共同决定：

1. 像素与颜色正确；
2. 人像、结构和生成结果自然；
3. 非破坏与可恢复；
4. 交互和批处理性能；
5. 跨设备、格式和版本兼容；
6. 安全、隐私和无障碍。

AI 质量不能只用一个相似度分数；自动指标、故障标签和人类盲评必须同时达标。

## 2. 基准硬件

`Reference`：

- 8 核现代 CPU；
- 32GB RAM；
- 8GB 显存或相当统一内存；
- NVMe SSD；
- 2560×1440 SDR 校准显示器。

`Minimum`：

- 4 核 CPU；
- 16GB RAM；
- 4GB 显存或支持的集成 GPU；
- SSD。

基准文档 `Perf-24`：6000×4000、16 位、10 图层、3 蒙版。性能报告使用 30 次运行 P95，冷/热缓存分开。

## 3. 性能预算

| 场景 | Reference P95 目标 |
|---|---:|
| 冷启动至可操作 | ≤ 3 秒 |
| 打开 24MP JPEG 首屏 | ≤ 1.5 秒 |
| 重开典型项目到上次视图 | ≤ 2 秒 |
| 平移/缩放帧耗时 | ≤ 16.7ms |
| Minimum 平移/缩放 | ≤ 33ms |
| 压感笔输入到显示 | ≤ 20ms |
| 常规滑杆首次反馈 | ≤ 50ms |
| 12 个预设首屏缩略图 | ≤ 500ms |
| 缓存预设切换 | ≤ 100ms |
| 24MP 人像一键预览 | ≤ 3 秒 |
| 24MP 天空替换预览 | ≤ 3.5 秒 |
| 移除 ≤15% 画面预览 | ≤ 4 秒 |
| 人像/天空 24MP Final | ≤ 12 秒 |
| 对象移除 24MP Final | ≤ 20 秒 |
| 典型增量保存 | ≤ 1.5 秒 |
| 自动保存引起的 UI 卡顿 | ≤ 50ms |
| 24MP 高质量 JPEG 导出 | ≤ 5 秒 |
| 典型工作集内存 | ≤ 6GB |
| 单任务显存占用 | ≤ 可用显存 80% |

这些是产品目标，不是无条件承诺。每次发布按 GPU/模型/图像难度报告分布；若某型号硬件不达标，必须有明确支持级别与降级说明。

其他硬性要求：

- 100MP 不要求整图驻留显存；
- 后台导出不阻塞画布；
- 用户取消后 500ms 内停止继续排队；
- 8 小时会话不存在持续线性内存增长；
- 缓存配额可调，默认建议 10GB。

## 4. 颜色与确定性

测试集合：

- ICC v2/v4、矩阵和 LUT 配置；
- sRGB、Display P3、Adobe RGB、宽色域工作空间；
- 8/16 位 TIFF、透明 PNG、HDR PQ/HLG；
- RAW 相机配置和高光；
- 软打样、黑点补偿和渲染意图；
- CPU/GPU 参考输出。

目标：

- 确定性颜色/混合操作跨已认证后端，中位 `ΔE00 < 0.5`；
- 非异常像素最大值原则上 `< 2.0`；
- 预览与最终导出在同一 view/output transform 下无可见逻辑差异；
- Alpha 边缘无非预期暗边/亮边；
- 16 位往返无明显色阶断裂；
- 非确定性生成节点用冻结补丁保证旧项目外观。

任何阈值豁免必须包含图像、区域、原因和批准人。

## 5. 功能视觉验收

| 功能 | 最低门槛 |
|---|---|
| 人像磨皮 | 单独磨皮时几何零变化；盲评 ≥90% 为自然/基本自然且仍有纹理 |
| 五官微调 | 默认幅度保守；每部位可复位；背景直线不变形 |
| 人像整体 | 非目标人物、衣物和背景无明显溢出；永久特征默认保留 |
| 风景 | 高光/阴影无大面积截断；山脊无明显光晕；区域可独立调整 |
| 宠物 | 普通/中等样例毛发、胡须和耳缘无明显断裂；盲评通过 ≥85% |
| 天空替换 | 普通难度 ≥90% 无明显白边、光晕或地平线穿帮；光色可解释 |
| 对象移除 | 简单/中等盲评自然通过 ≥85%；失败区域被 QA 标出 |
| 预设 | 真实图预览；肤色保护有效；批量自适应不产生明显漂移 |
| 自然语言 | 意图 Top-1 ≥95%；目标范围 ≥98%；高风险漏确认 = 0 |

指标只用于发布门禁，不用于掩盖困难样例。每项必须分“简单 / 中等 / 困难”报告，并公开失败分类。

## 6. AI 故障标签

### 人像

- 皮肤塑料化、纹理重复；
- 痣/雀斑被误删；
- 眼睛/牙齿纯白；
- 五官几何、虹膜、嘴唇异常；
- 背景弯曲；
- 非目标人物被修改；
- 肤色分块或偏移。

### 抠图与换天

- 发丝/毛发/树叶丢失；
- 白边、黑边、原背景溢色；
- 地平线接缝；
- 锐度、噪点、景深不一致；
- 光向、色温和反射不一致。

### 移除/生成

- 重复纹理；
- 结构线断裂或透视错误；
- 阴影/反射中断；
- 模糊斑和接缝；
- 文字/标志畸变；
- 新增异常人物、肢体或物体；
- 生成区域越界。

## 7. 测试层级

| 层级 | 内容 | 门槛 |
|---|---|---|
| 单元 | 数学、混合、颜色、坐标、参数、脏区 | 关键分支全覆盖 |
| 属性 | 序列化往返、DAG 无环、撤销/重做、随机尺寸 | 不变量零失败 |
| 金图 | 滤镜、蒙版、混合、导入/导出 | 超阈值变化需人工批准 |
| CPU/GPU 差分 | 后端与精度 | 通过颜色/数值预算 |
| 集成 | 打开、保存、迁移、重链、模型降级 | 支持矩阵全通过 |
| UI/E2E | 快捷、专业、批量、语言、取消、恢复 | P0 旅程 100% |
| AI 评测 | 自然度、身份、边缘、结构、伪影 | 指标 + 盲评 |
| Fuzz | 图片、项目、命令、清单、IPC | 无崩溃/越界/资源失控 |
| 安全 | 权限、路径、网络、签名、沙箱 | 无未解决高危 |
| 故障注入 | 断电、磁盘满、GPU reset、Worker 崩溃 | 已提交事务不丢 |
| 性能 | 延迟、吞吐、RAM/VRAM、缓存 | P95 达预算 |
| 长稳 | 8 小时编辑、批量、反复撤销 | 无泄漏和损坏 |
| 无障碍 | 键盘、读屏、对比、缩放 | 核心流程可完成 |

## 8. 测试素材矩阵

### 图片

- 12/24/45/100MP；
- JPEG、PNG、TIFF、HEIF/AVIF、主流 RAW；
- 8/16/32 位、透明、HDR；
- 超长路径、中文、Emoji 和不同文件系统；
- 损坏、截断、恶意尺寸和异常元数据。

### 人像

- 不同肤色、年龄、性别表达和光照；
- 婚纱/头纱、眼镜、首饰、妆容、侧脸、遮挡；
- 儿童、老人、多人、混合景深；
- 痣、雀斑、疤痕、皱纹等永久特征；
- 低分辨率、压缩和高 ISO。

### 风景/宠物/修复

- 细树枝、电线、复杂建筑和水面；
- 日落、夜景、雪地、雾、HDR；
- 长毛/短毛、黑毛/白毛、多宠物、人宠遮挡；
- 道路标线、栏杆、砖墙、文字和重复纹理；
- 阴影、反射和大面积遮挡。

真实用户照片不会自动进入测试集。每个素材必须有来源、许可、用途和到期策略。

## 9. 平台矩阵

- Windows 支持版本：NVIDIA、AMD、Intel 独显/核显；
- macOS 正式版及前一版：Apple Silicon；
- 16GB 最低、32GB 推荐；
- 4GB/8GB/更高显存和统一内存；
- 纯 CPU 和离线降级；
- SDR/HDR、单/双显示器、不同 UI 缩放；
- 鼠标、触控板、Wacom 类压感笔；
- 中文和英文。

Linux 可作为后续或无承诺实验目标，不稀释 1.0 的 Windows/macOS 质量。

## 10. 可靠性指标

- Beta 无崩溃会话率 ≥99.8%；
- Stable ≥99.95%；
- 10,000 次随机故障注入中已提交事务零丢失、零不可恢复损坏；
- 连续 1,000 次命令/撤销/重做后文档哈希正确；
- 用户取消的任务不会在后台晚到后提交；
- 模型、插件或 Worker 崩溃不损坏主项目；
- 原图覆盖事故为零。

## 11. CI 与发布门禁

每个变更：

- 编译、格式、静态分析、单元和 Schema；
- 核心金图与项目往返；
- 依赖和密钥扫描。

每日：

- 全量金图、跨后端差分；
- AI 小评测、UI E2E；
- 主要性能基准和内存趋势。

每周/候选版：

- 完整模型评测与盲评抽样；
- 支持平台矩阵；
- Fuzz、故障注入、长稳；
- 安全和许可证；
- 旧项目迁移语料库；
- 安装、更新和回滚。

发布阻断：

- P0/P1 缺陷；
- 高危安全问题；
- 原图/项目损坏；
- 未授权网络；
- 颜色、模型或性能超门槛且无批准豁免；
- 缺少模型/素材许可证；
- 高风险操作漏确认。

## 12. 功能完成定义

一项功能只有同时完成以下内容才算交付：

- 行为、失败状态和非目标已写入规格；
- 命令 Schema、默认值和迁移冻结；
- 自动、手动、取消、撤销和重做可用；
- 离线、低内存和模型缺失有降级；
- 单元、金图、集成、E2E、性能和安全覆盖；
- 有合法可复现评测集和模型卡；
- 无障碍、键盘、本地化和错误文案完成；
- 日志、缓存、网络通过隐私检查；
- 用户帮助与故障排查完成；
- 达到预算或获得有期限的书面豁免。
