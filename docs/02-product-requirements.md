# 产品需求规格（PRD）

## 1. 范围与优先级

- `P0`：首个可公开测试版必须完成；
- `P1`：专业版 1.0 必须完成；
- `P2`：1.x 增强能力；
- `P3`：探索项。

验收中的“保持自然”不能只由开发者主观判断，必须同时通过自动检查、双尺度视觉检查和至少两名目标用户的盲评。

## 10. 关键端到端验收场景

### 场景 A：自然婚纱照精修

导入 45MP RAW → 一键人像 → 保留痣 → 减少油光和黑眼圈 → 新娘和新郎分别微调 → 预设强度 35% → 分屏对比 → 导出 16 位 TIFF 与网页 JPEG。全程可撤销，肤色不因预设发生明显偏移。

### 场景 B：移除路人

用户圈选道路上的路人并输入“连影子一起去掉，黄色道路线要保持连续” → 系统显示目标蒙版与三步计划 → 生成三个候选 → 标记一个疑似重复纹理区域 → 用户换用第二候选并锁定道路线 → 全分辨率完成。

### 场景 C：宠物换背景

识别长毛猫 → 保留胡须和蓬松毛边 → 清理泪痕但保持眼睛结构 → 替换为浅色室内背景 → 自动匹配景深与接触阴影 → 手动画笔补回一小撮毛发。

### 场景 D：自然语言复合修改

“天空换成日落，人物别变黄，后面的垃圾桶去掉，再让整体有一点电影感但不要太暗。”系统应拆出天空替换、人物保护、对象移除和预设四个节点；先给低分辨率候选，说明云端需求（如有），再执行全分辨率。

## 11. 发布阻断条件

出现以下任一情况不得发布：

- 能覆盖或损坏原始文件；
- 项目恢复可能产生不可检测的半完成状态；
- 高风险外貌修改可在无预览、无确认下批量执行；
- 云端上传范围与界面说明不一致；
- 颜色管理关闭或失效但未警告；
- AI 模型更新没有版本、评测和回滚路径；
- P0 性能或视觉回归超出文档 11 门槛。
